## 📌 Project Overview

This project implements a CMOS-based Full Adder using PMOS and NMOS transistors in LTspice. The design performs binary addition of three inputs (A, B, Cin) and generates Sum and Carry outputs.

---

## 🎯 Objectives

✅ Design a transistor-level Full Adder

✅ Verify truth table functionality

✅ Analyze transient response

✅ Study CMOS implementation techniques

---

## 🧠 Working Principle

A Full Adder is a combinational logic circuit that adds:

* Input A
* Input B
* Carry Input (Cin)

and generates:

* Sum Output
* Carry Output (Cout)

The circuit is implemented entirely using CMOS technology to achieve low static power consumption.
