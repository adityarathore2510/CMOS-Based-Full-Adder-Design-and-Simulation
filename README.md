# CMOS-Based Full Adder Design and Simulation

## Overview
This project presents the design and simulation of a CMOS-based Full Adder using LTspice. The circuit performs binary addition of three input bits and generates Sum and Carry outputs.

## Principle
A Full Adder adds three binary inputs (A, B, and Cin) and produces:
- Sum Output
- Carry Output

The design uses CMOS logic, which combines PMOS and NMOS transistors to achieve low power consumption and high noise immunity.

## Features
- CMOS implementation
- LTspice simulation
- Truth table verification
- Transient analysis

## Tools Used
- LTspice
- CMOS Technology

## Results
The simulated outputs matched the theoretical Full Adder truth table.
